# 🐜 ANT CLAW Design System

## Brand Direction

ANT CLAW uses a clean AI command center style.

No gaming style. No unnecessary effects.

Professional, technical, simple.

## Logo

Primary logo:

- ANT symbol
- Orange accent
- Dark graphite details
- Clean app icon

## Light Mode

Colors:

```
Background: #FFFFFF
Surface: #F7F7F7
Text: #1A1A1A
Primary Accent: #FF7A00
Secondary Accent: #FF9D3D
```

Feel:
- Bright
- Clean
- Modern

## Dark Mode

Colors:

```
Background: #121212
Surface: #1E1E1E
Card: #252525
Text: #FFFFFF
Primary Accent: #FF7A00
Secondary Accent: #FFB15C
```

Feel:
- Technical
- Focused
- Premium

## Main Screens

```
Home
Chat
Agents
Memory
Settings
```

## Components

- Orange action buttons
- Rounded dark/white cards
- Status indicators
- Agent cards
- ANT DEV update panel

## Product Rule

Every screen must support both:

1. Light mode: white + orange
2. Dark mode: dark grey + orange

The design must stay simple and fast.
