# 🐜 ANT DEV CORE

## Role

ANT DEV CORE is a GitHub engineering agent system.

It is NOT an APK feature.

Its mission:

- Read repository code
- Monitor builds
- Fix errors with patches
- Test changes
- Study AI engineering trends
- Report updates

## Operating Model

```
ANT DEV CORE
      |
      +-- Code Repair Agent
      +-- Build Agent
      +-- Test Agent
      +-- Research Agent
      +-- Security Agent
      +-- Report Agent
```

## Continuous Loop

```
Scan
 ↓
Analyze
 ↓
Patch
 ↓
Test
 ↓
Report
 ↓
Improve
```

## Repository Rules

- Keep ANT DEV code separate from Android APK code
- Avoid duplicate agent workflows
- Keep one source of truth for agent status
- Validate every patch before release

## Future Connections

- GitHub Actions logs
- AI trend monitoring
- Error memory
- Verified pull requests
- Live reports
