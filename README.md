# 🧠 Omni Router Architecture

```text
                 ANT CLAW
                    |
              Omni Router
                    |
       +------------+------------+
       |            |            |
    Ollama       Cloud       Custom
    Local AI     Models      Providers
```

The router allows ANT CLAW to support multiple AI providers while keeping one chat experience.
