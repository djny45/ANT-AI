# 🚀 Local Setup

Requirements:

- Node.js
- Python 3.10+
- Docker
- Ollama


Clone:

```bash
git clone https://github.com/YOUR_USERNAME/ANT-AI.git

cd ANT-AI
```

Environment:

```bash
cp .env.example .env
```

Run:

```bash
docker compose up
```
