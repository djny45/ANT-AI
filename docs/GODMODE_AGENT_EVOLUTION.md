## Agents

- Master Agent: orchestration and decision coordination
- Research Agent: information gathering and analysis
- Coding Agent: software engineering workflows
- Planning Agent: task decomposition
- Memory Agent: knowledge management
- Security Agent: security review
- GitHub Agent: repository lifecycle management
- Automation Agent: workflow execution
- Devil Advocate Agent: risk analysis and challenge system decisions

## Agent Requirements

Every agent must have:

- identity
- mission
- tools
- memory scope
- permissions
- evaluation metrics
- audit logging
