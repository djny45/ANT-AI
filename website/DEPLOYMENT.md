# ANT Website Deployment

## Current Build

- Static HTML/CSS/JavaScript architecture
- InfinityFree compatible
- No server dependency for the frontend layer
- Mobile optimized interaction flow

## Upload Structure

```
website/
├── index.html
└── assets/
    ├── ant.css
    ├── ant-engine.js
    ├── ant-state-engine.js
    ├── ant-ai-connector.js
    ├── ant-visual-controller.js
    ├── ant-performance.js
    ├── ant-sphere-active.js
    ├── ant-state-bridge.js
    ├── ant-auto-loop.js
    └── ant-main-event-controller.js
```

## Deployment Steps

1. Upload the contents of `website/` to the public web folder.
2. Confirm `index.html` loads first.
3. Test sphere animation on mobile and desktop.
4. Connect AI backend when ready.

## Design

- Grey background
- Orange holographic sphere
