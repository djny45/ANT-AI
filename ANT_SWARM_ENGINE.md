# 🐜 ANT CLAW Swarm Engine

## Vision

ANT CLAW uses a coordinated agent architecture where specialized workers operate under the ANT Core intelligence layer.

## Architecture

```
ANT CLAW CORE
      |
 Omni Router Brain
      |
+-----+-----+-----+
|     |     |     |
DEV  AI  SECURITY TEST
ARMY ARMY   ARMY   ARMY
```

## DEV ARMY

Purpose: software engineering and maintenance.

Workers:

- Kotlin worker
- Compose worker
- Gradle worker
- Refactor worker
- Build worker
- Release worker

## AI ARMY

Purpose: intelligence operations.

Workers:

- Ollama manager
- Model selector
- Prompt optimizer
- Context manager
- Memory worker

## SECURITY ARMY

Purpose: protection.

Workers:

- Secret scanner
- Dependency checker
- Permission reviewer
- APK security checker

## TEST ARMY

Purpose: reliability.

Workers:

- UI tester
- API tester
- Regression tester

## Command Center

Future APK screen:

```
ANT COMMAND CENTER

DEV ARMY       ACTIVE
AI ARMY        ACTIVE
SECURITY ARMY  ACTIVE
TEST ARMY      ACTIVE
```

## Design Rule

Agents operate as controlled workers managed by ANT Core.

Priority:

1. Working code
2. Verified changes
3. Security
4. Improvement
